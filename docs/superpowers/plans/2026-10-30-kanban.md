# Personal Kanban implementation plan

Goal: A private, polished personal Kanban dashboard, deployed from GitHub to Vercel.
Architecture: Next.js client application with Supabase email-link authentication and Postgres row level security. Every data operation requires the owner's verified email and row ownership. No service-role credentials in the app.

- [ ] Implement email-link login and session handling, locked to the connected GitHub account email.
- [ ] Create boards and cards schema with owner-only RLS; verify anonymous and other-user access is denied.
- [ ] Build responsive board navigation, card editing, drag/drop, status actions, search, priority filters and archive/delete.
- [ ] Install Analytics component and configure Vercel environment and Next.js build.
- [ ] Run typecheck, production build, database security checks; push and inspect deployment.
- [ ] Document Linear issue workflow and distinguish connected issue tracking from unattended fixes.

Review focus: unauthorized users; expired sessions; failed writes; dragging while filtered; empty boards. All database errors must be visible and must not silently discard edits.
